# PocketAgent 完整研究工作流

更新日期：2026-11-08。当前默认工作台仍以 CPU 策略研究为主，旧神经网络训练路径作为可选兼容入口保留，运行依赖分离在 `requirements-training.txt`。

## 研究模式

| 模式 | 计算方式 | 结果含义 |
| --- | --- | --- |
| 单次回测 | 一个策略、一个独立单股账户 | 可执行净值和成交报告 |
| 批量参数 | 有限参数网格、串行 CPU | 样本内候选排名；候选完整报告按需读取 |
| 滚动验证 | 过去训练窗口选参，后续窗口验证 | 样本外窗口分布；最终测试段默认保留 |
| 向量化粗筛 | 训练区间的近似信号和成熟未来标签 | 假设筛选，不能替代净成本回测 |
| 逐股票对照 | 每只股票独立完整账户 | 跨股票分布，不制造平均 NAV 曲线 |
| 共享现金组合 | 多股票一笔现金、同时持仓、调仓 | 真实组合 NAV、共享资金、stale valuation |

所有模式读取数据时都保留输入快照、配置身份、实现 SHA-256、失败记录和假设。多机器任务包会再绑定环境、计划和任务 ID。

## 结果稳健性

批量完成后可以请求成本敏感性、跨年份表现、交易集中度、相邻参数稳定性、Deflated Sharpe Ratio 和 CSCV PBO。诊断输入来自该次实验完整登记的成功候选及其日收益；失败候选、缺失尝试和未登记的人类搜索不会伪装成“没有发生”。

DSR 的 trial count 默认是该记录中成功候选数量，只有在明确给出独立试验数时才改变假设；高度相关的参数网格不能当作完全独立的试验。CSCV 仅是选择偏差诊断，不能替代按时间滚动验证或最终保留测试。

成本敏感性会重新运行同一策略并改变费用／滑点倍数，结果单独保存；它不会修改原始配置。跨年份统计只在实际记录的日终日期上分组，交易集中度明确排除未平仓，并保留统计单位。

## 市场与行业上下文

`feature_layer.context.enrich_daily_bars` 接收 benchmark、industry 和 membership 数据，要求每条参照数据有 `available_at`，历史行业映射有 `valid_from`、`valid_to` 和 `known_at`。决策收盘前不可用的参照值会被标成 unavailable；严格模式直接报错。上下文特征的窗口是 observed bars，不把 20 根 K 线写成 20 个日历日。

`context_momentum` 只在当时可见的指数／行业上下文满足条件时开仓；缺失上下文阻止新买入，但不禁止根据已知个股变弱信号退出。demo context 显式标记为 synthetic。外部 context 路径在离线任务导出时会被固化进输入快照，worker 不重新下载或从当前文件夹补造。

## 组合和逐股票研究

组合模式只有一个 `PortfolioAccount`，先卖后买，目标权重经过专门适配器转换为执行容量，不能把 target weight 直接当成单股 size。每只股票共用现金、费用、整手和 T+1 规则；缺失当日行情不成交，持仓可以使用最后已知价格但会标记 stale。

逐股票模式相反：每只股票独立使用初始现金，汇总只提供均值、中位数、正收益比率和覆盖期诊断；顶层曲线选择确定性第一只成功股票用于查看，不能当作组合曲线。

历史 `is_member` 事实和静态用户股票池分开记录。静态股票池不自动宣称无幸存者偏差，严格组合模式要求逐日历史成员事实。

## 轻量 CPU 模型

`ridge_forecast` 使用 NumPy Ridge，scaler 和权重只用已经成熟的历史标签；标签是未来 close／当前 close 收益，不是直接可获得的下一开盘收益。验证期间只使用已经到达的标签在线更新，超参数冻结。它仍然通过同一个订单执行器，不绕过费用、流动性、ST、涨跌停和 T+1。

`constrained_random` 使用固定 seed，只从信号时已知账户和市场允许的方向抽样；它是对照策略，不是训练结果。

## 离线机器任务

使用 `python -m research_layer.cli.offline prepare` 固化任务计划。包内含输入 CSV、任务配置、源代码快照、依赖说明、数据／实现身份和 shard。worker 使用已安装的 PocketAgent 计算代码，包内 source 只供审阅，不会自动执行。

worker 可按 shard 或 task ID 运行；完成标记有 SHA-256，重复运行会复用完整任务，失败任务需要显式 `--retry-failed`。结果包导入时校验计划、配置、数据和实现身份；同语义重复结果去重，冲突拒绝，缺任务汇总状态为 incomplete。

`python -m research_layer.cli.resume --run <run_dir>` 会创建新恢复 run。只有有 `artifacts.json` 且 SHA-256 全部通过的候选／fold 才复用；旧 run 不覆盖，旧 run 缺索引时明确重新计算，不把重算说成恢复。单次账户任务按完整账户边界恢复，不切半段账户拼接收益。

## 训练路径边界

默认首页、研究 API、CPU 依赖和研究 CLI 均不导入 PyTorch。旧 Agent／Evaluation 控制器保持可选兼容，训练依赖单独安装；训练模型、checkpoint、训练日志和缓存继续作为用户资产保留。

训练源码不会因为策略工作台验收而被静默删除。后续清理要求先保存源快照、检查活跃 imports 和 legacy UI 路由，迁移仍有价值的账户／时间流／执行测试，再独立归档训练源码。研究工作流不依赖训练源码才能视为完成解耦。
