# 训练主线边界

2026-11-08。PocketAgent 的默认产品入口已经是 CPU 策略研究工作台，训练主线不再是默认运行路径。

## 已完成的清理

- `requirements.txt` 只保留 CPU 研究、数据和 Dashboard 依赖；原 CUDA／PyTorch 依赖单独放在 `requirements-training.txt`。
- Dashboard 首页进入策略研究页；研究 API、离线任务、组合回测、上下文特征和轻量模型都不导入 PyTorch。
- Agent 与旧模型评估 controller 通过可选 lazy bridge 调用。没有训练依赖时，研究流程保持可运行，旧训练请求明确返回可选依赖错误。
- 账户、动作、执行器和通用时间流保留，训练模型、PPO、reward、worker、validator、DDP 和 Agent Cache 仍作为兼容资产，不允许在没有迁移证据时删除。
- 现有模型、checkpoint、训练日志、缓存和论文全部列入受保护运行资产；清理源码不等于清理这些数据。

## 仍保留的原因

当前旧训练代码仍被 legacy Evaluation／Agent 页面、历史 checkpoint 回放和部分兼容测试引用。直接删除会让可恢复的历史研究路径消失，也可能误删用户资产。因此本轮采用“退出默认流程、保留可选兼容层”的有边界清理。

如果未来要彻底删除训练源码，必须先完成以下条件：

1. 账户、执行器、行情时间流和现有行为测试已完全迁入 CPU 核心。
2. legacy UI、路由、CLI、包初始化和文档不再导入训练模块。
3. 所有需要保留的 checkpoint 元数据和结果已归档，并能从归档恢复说明中读取。
4. 没有活跃 run、导出任务或用户未提交文件依赖待删除路径。
5. 删除前生成完整源代码归档并做 SHA-256、导入路径和最小兼容测试。

当前状态满足“研究产品与训练依赖解耦”，但不声称训练历史已被删除。这个边界保护了用户已有模型和实验，同时让日常策略研究不再需要 GPU 或 PyTorch。
