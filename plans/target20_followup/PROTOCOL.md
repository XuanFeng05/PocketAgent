# 月度选股、空仓和收益来源复核

2026-11-26，原100股、2022–2025历史已被多次查看。本轮沿用不加杠杆、账户CAGR>20%、最大收盘净值回撤≤15%的目标。以下选股对照在读取其结果前登记。已知上轮6项候选结果及本轮原账本的逐股初步归因，属事后提出的机制研究。

1. 复核原策略逐股净损益、隔夜和日内损益、费用，检查损失广度和盈利集中度。分母为各段期初账户净值。
2. 逐月按上月末已知广度分组，从调仓开盘到下一调仓开盘比较原5股名单与100股等权的后续表现。对同一5股波动率管理账户，只移除广度清仓条件，重跑共同现金账本。预先分组、事后观察收益。
3. 检验原63/126日强弱排名本身有多少作用。比较原10股强势组合与原5股防守组合。每个原组合的月度资格集合、最大持股数、缓冲规则、调仓日期和总目标仓位固定，只更换排序依据。三个确定性名单分别为原强弱排名、忽略最近21个交易日的强弱排名、过去63个交易日实现波动较低者优先。跳过最近一个月的分数为原两段收益各自扣除最近21日对数收益，起点仍为原63/126日回看起点。此对照仅检验符合原入选资格的股票之间的排序。
4. 每个原组合再生成256组与收益无关的固定股票优先顺序，用NumPy PCG64种子20261126一次性生成。每月在当时合格股票中按该顺序选取，沿用相同缓冲与资金槽。所有模拟完整运行有成本的共同现金账户。报告原排名在参考分布中所处位置及中位数。固定随机优先级控制具有不同的名单稳定性和实际换手，零成本诊断帮助识别费用影响。256组只用于参照，不能从中选一个历史赢家推广。
5. 5股防守方案还将两种替代排名各自接回基于实际入选5股的原12%波动缩放和50%广度条件，作为可执行的完整策略；对比固定原总仓位时的变化。10股组合本身不使用波动缩放。只检查固定0/10/20bps，不增添持仓数、周期或阈值搜索。记录年收益、回撤及是否达标；没有未见测试集。

沿用原模拟账户可分割合成份额、次交易日开盘成交及全日量作为停牌代理等假设。月度出手频率另报实际成交笔数。原账本复现、逐日会计核验和现金基线均通过后才解释结果。

初次归因后追加三项单独登记的检验。隔夜筛选只使用月末已知的最近63个隔夜收益，保持原强弱排名。市场广度关门时，等权100股替代篮子与继续持有5股采用相同的月度总股票预算。两项检验的登记和执行见各自脚本与协调记录。针对300308.SZ的净贡献集中，在看到递补模拟结果前登记逐股删除诊断：对100个代码逐一假设全期不可买，防守5股按相同的缓冲和资格规则递补，原广度、全市场数据和原总风险预算保持；若不足5个名额按原槽位留现金。只用单边10bps。此项用于量化单一个股对结果的影响，不能据此事后挑选剔除对象作为交易策略。
