# 2026-11-26 四项研究的执行计划

沿用本地100股前复权日线、2022–2025年、成本主口径单边10bps及T+1。账户目标为年化超过20%、收盘净值最大回撤不超过15%。历史数据曾多次查看，以下均为探索。

1. 在周线双EMA上升且日低落入均线带的日期中，配对EFI2恢复与未恢复的同股样本，比较次日开盘起第5、20个交易日的净收益及不利波动。记录样本损失和市场状态差异。
2. 固定真实严格AND买点，比较0.25ATR盘中跟踪与激活后首次收盘低于前一日低点才排队卖出；保留0.5ATR初始止损、T+1及持仓后三连收盘低于EMA26的退出，列出放大利润和回吐的代价。按新持有时间重新检查后续入场机会。
3. 月末先决定可以买哪些股票和投入多少，比较直接建仓与预留现金等待当月首个严格AND信号。保留原月度退出规则，报告错过的机会和账户结果。各项匹配、卖出及同步细则先登记在对应研究记录中。
4. 市场偏弱时分散持有100股、恢复时持5股的账户原有3580笔买卖。主对照完全复用原名单和总目标仓位。月末名单及总权重都未变则跳过调仓。发生变化时，退出名单者目标归零，新入名单者按原计划金额建仓，仍持有者先保留原份额。若还须改变股票总额，则向低于原等权目标且金额缺口最大的保留股先买，或从超配金额最大的保留股先卖；每次最多向原单股目标靠近，满足总额就停止，同值按代码先后。这个固定的执行选择旨在减少同时买卖保留股的次数。另设每月都恢复原股票总预算的对照，允许保留股间相对权重漂移。按0/10/20bps全部列报，比较笔数、成交日期、双向换手、净年化、最大回撤、平均暴露和最大单股权重。成交沿用原开盘价同时确定份额和成交的技术约定；停牌仍会导致目标和实际预算有差异。

第2项和第3项使用的退出规则不同。第2项检查单笔卖法，第3项独立检验月度选股加日线择时。若将第2项信号流分配给共享账户，最多5只等额资金槽，超过名额时按代码排序，只在新开仓时配额，先清算可用的开盘卖出，盘中卖出资金从次日才可用于新开仓。分别记录机会被名额和现金限制的程度。该账户结构属于研究选择。
