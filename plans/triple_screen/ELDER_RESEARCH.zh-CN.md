# Elder经典规则与有限组合研究

本分支以`21cd849`为基础，新增独立US研究模块，保留本地页面修复。它不是此前`bf0c0ab`美股页面整合包的完整替代；本轮云端重建环境，旧工作目录、行情快照和运行工件不可用，重新下载必须标为新版本。

## 规则身份

参考Alexander Elder《Trading for a Living》(1993)第43、47、48节。原著给出多种信号和退出方式，并非唯一的完整机械算法。本轮先做**经典多头、日线可执行近似**，不声称完整重现书中的盘中操作、多空、加仓和组合资金管理。

两项登记基线：

- `classic_position`：完成周MACD12/26/9方向、日EFI2启动持续买入挂单；保护止损、保本和50%浮盈保护，周方向反转退出。
- `classic_swing`：相同入场与止损，另有EFI2转正退出；保留周方向反转退出。

持仓型退出有原著依据，不能因为旧回测卖早了就断言周线退出错误。旧实现真正需要区分的还有持续挂单、动态保护止损和风险定仓。原著明确讨论保本和利润保护，但精确的启动幅度、回看长度和日线处理方式需另行规定。

原文参考：<https://djvu.online/file/SfsruSSthleHx>（第241、243、260、267–268页）。Impulse属于后续版本/探索变体，不混称1993经典基线。

## 日线机械化约定

- 只读取当时已完成的自然周；纽约实际收盘与提前收盘进入交易日历。前一交易日收盘信号决定下一日订单。
- EFI<0启动候选；未成交时逐日下调买入线，直至成交或周方向反转。EFI次日转正本身不撤销已激活的挂单。
- 触发线为上一完成日high加0.01**调整美元研究缓冲**。Yahoo历史报价可能已拆股调整，不能把该缓冲声称为当时交易所的真实一tick。
- 初始stop使用上一完成日low减同一缓冲。这是图示启发的已知信息近似；不读取入场日最终low反填入场时止损。精确入场时低点需分钟/逐笔数据。
- 收盘价相对入场价有利移动达到入场前ADR20后，启动含费保本及50%/70%浮盈保护。ADR20、阈值及收盘确认是研究约定；新stop只在下一交易日生效且不得放宽。
- 盘中入场日不假定该日最高价发生在买入之后；峰值先取入场价与收盘价较高者，随后已完整持仓日才使用high。
- 开盘越过触发/止损按开盘价；同日盘中入场与止损均触及时采用保守顺序并单列歧义，不删除亏损交易。
- 每个独立股票账户按1%计划权益风险（含估算双边费用）决定持仓，现金不足则降低仓位，无杠杆。跳空可使实际损失超预算。
- 100个等初始资金独立账户合计NAV，无跨股票调仓或共享资金。主实验现金利息为0；仅训练阶段选出的组另做官方RF日利率现金代理敏感性，不称实际券商计息。
- 净胜率以扣费正收益为赢；含费保本单独计数，仍计入总笔数，防止浮点误差把保本交易算赢。

## 组合与选择

配置`config/research/elder_search_v1.json`固定72组：3种周过滤 × 2种EFI周期 × 3种退出 × 4种止损。固定股票清单不增删；不同规则不是重新筛选股票。

先完成2022–2023全部训练组，再按预设规则冻结ID：收益/回撤较优的前5组、净盈利候选中胜率最高的一组、收益最高的一组，保留两基线。只有完成冻结，才运行2024–2025回顾性验证。所有候选和失败均保留，不能只报赢家。两段各从新账户开始，并用2020以来行情预热；不是可以直接拼接的可交易换参组合。

这些年份已经看过，不是全新样本外。验证同时报告净收益、CAGR、回撤、胜率、不亏率、盈亏比、成本、歧义、资金暴露；使用同步日期区块bootstrap、Holm及候选族max-mean检验，不能仅凭多次尝试里的最好结果宣称发现稳定盈利策略。

## 运行

```bash
python -m venv .venv
# Windows使用 .venv\Scripts\python；Linux使用 .venv/bin/python
python -m pip install -r requirements-research.txt
python -m research_layer.elder_data --probe
python -m research_layer.elder_data
python -m research_layer.elder_data --audit-only
python -m research_layer.cli.elder_search --stage all
python -m research_layer.cli.elder_baselines
```

在已激活独立环境下运行上述命令。下载器使用固定`config/universe/us_research100.txt`，仅Yahoo日线2020-01-01至2026-07-12，串行、网络超时、原响应与SHA保留。完整运行建议外层1800秒超时；失败仅用`--only SYMBOL ...`重试失败清单，不替换股票。2026数据仅质量检查。

`--stage train/validate/costs/analyze`支持分阶段操作；训练阶段完成后写`frozen_selection.json`，恢复时校验数据、源码及配置身份，禁止无声覆盖。所有数据与运行结果位于被Git忽略的`runtime_layer`。云端下载成功与单元测试通过不等于浏览器、Windows实盘或盈利能力验收。

`elder_baselines`仅对已登记的两项基线做2022–2025全期描述，不参与选参。主实验费用为**单边10bps**，候选另检查0/5/10/20bps。计息敏感性仅覆盖训练冻结的选择；其区块检验报告单独生成，不用零计息72组的统计结论代替。PSR/DSR是IID与假设有效试验次数下的辅助诊断，不是过拟合概率或策略合格证。

当前股票清单是既定存续股票样本，存在幸存者偏差；买入持有基准为相同100股全额持仓，与风险定仓策略的暴露不同。下一轮规则改变应另存配置和运行目录，累计记录尝试次数，禁止把反复观察过的日期重新标成未见测试。新一轮要提高净收益与胜率，可按退出、止损、信号条件和资金使用分别设计对照；不能用降低成本假设或扩大风险冒充信号质量提升。
