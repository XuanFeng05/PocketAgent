# M6：参数邻域与滤网移除的预登记研究

登记时间：2026-11-12，运行前登记。仅用已有本地数据，不下载/联网/安装。固定区间为2022-01-04~2024-12-31，股票清单复用local100_request_20261112.json，单边比例摩擦10bps。属于已暴露样本的探索研究，不是untouched测试，也不选最优策略。

## 固定案例

| ID | 修改 | 目的 |
|---|---|---|
| primary | 完整v1，MACD12/26/9、EFI2 | 对照锚点 |
| fast10 | 仅MACD快周期12→10 | 快周期邻域 |
| fast14 | 仅MACD快周期12→14 | 快周期邻域 |
| slow24 | 仅MACD慢周期26→24 | 慢周期邻域 |
| slow28 | 仅MACD慢周期26→28 | 慢周期邻域 |
| force1 | 仅EFI平滑2→1 | 回调平滑邻域 |
| force3 | 仅EFI平滑2→3 | 回调平滑邻域 |
| drop_weekly | 移除周线入场过滤及周转弱退出 | 检查完整第一滤网的作用 |
| drop_pullback | 移除EFI2<0入场过滤，周方向/突破/退出保持 | 检查第二滤网作用 |
| drop_trigger | 前两层通过后下一开盘直接入场，不等突破 | 检查第三层时机作用 |

所有案例仍保持100完成周预热、只做多/空仓、初始止损、T+1、停牌、无当日退出重入和同一成本。drop_trigger若开盘不高于初始止损，拒绝无有效风险距离的候选；不强行买入。drop_weekly仍计算并记录原始周指标，不能伪造weekly_up=true。

## 验收与解释

- 总任务100股×10案例×1成本=1000，先登记协议与代码哈希，后运行；全部失败保留。
- 原v1默认full的交易与净值必须与此前保存结果一致；新增对照功能不能改变基准行为。
- 每个案例与primary按同股票、同实际评价日期、同数据/日历哈希配对。不能把两股较短预热区间硬混成共同起止。
- 输出参数邻域及消融的配对收益差、回撤差、交易次数/歧义变化、样本数、失败和不匹配原因；不只展示收益最高者。
- 因为已有样本曾被查看，结果只能说明这些本地样本的敏感性与滤网影响；不能证明历史全A股或新日期有效性。
- 未解决的数据版本问题另列，不因当前所有任务通过而认定数据商调整版本已验证。
